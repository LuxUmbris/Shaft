### Setup
```
git clone -b bootstrap https://github.com/LuxUmbris/Shaft.git
cd Shaft
```

### Issues
Before you create an issue, make sure there is no other one of the same kind.

### Atmosphere
Follow the rules of our [Code of Conduct](CODE_OF_CONDUCT.md).

## AI Usage Policy

Generative AI tools (e.g., ChatGPT, GitHub Copilot, Claude) may **only** be used for:
* Writing unit/integration tests
* Drafting configuration files (e.g., CI/CD pipelines, Dockerfiles)
* Writing installation scripts and documentation

Do **NOT** use generative AI to write or generate the core source code for this repository. 

Contributors must fully understand, review, and take full ownership of all code, configs, and tests they submit.
